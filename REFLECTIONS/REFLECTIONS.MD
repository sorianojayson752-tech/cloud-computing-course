# Cloud Computing Reflection Paper

### Prepared by: Jayson Soriano

Cloud computing has become an important part of my daily life because many of the applications and services that I use depend on cloud technology. These platforms allow me to communicate with others, store important files, and access information whenever I need it.

Three cloud services that I frequently use are Google Drive, Messenger, and Canva. Google Drive is an example of Software as a Service (SaaS) because it allows users to store and manage files through an internet connection. It uses a public cloud deployment model because it is accessible to millions of users around the world.

Messenger is also classified as Software as a Service (SaaS) because it provides communication services through mobile devices and web browsers. Since it is available to a large number of users, it operates through a public cloud environment.

Canva is another example of Software as a Service (SaaS). It enables users to create presentations, posters, and other graphic designs online. Like Google Drive and Messenger, Canva uses a public cloud model to provide convenient access to its services.

Version control is an essential part of cloud computing because it helps developers track changes, identify errors, and restore previous versions of files whenever necessary. GitHub makes collaboration easier by allowing teams to work together efficiently while maintaining an organized record of all modifications.

Learning Git and GitHub will help me become more familiar with cloud technologies and prepare me for future opportunities in the field of information technology.
